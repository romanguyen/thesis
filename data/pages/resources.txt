====== Resources ======
Overview of computing, network, and storage resources available through MetaCentrum.

===== Computers =====
The National Grid Infrastructure coordinates the provision of computing resources to users using so-called Virtual Organizations.

List of machines provided by the VO MetaCentrum is available on the following page:

[[https://metavo.metacentrum.cz/pbsmon2/hardware|View Hardware List]]

===== Network =====
The core element of the whole CESNET e-infrastructure is the high-speed CESNET2 network. Main university cities of Czech Republic are connected into effective backbone. CESNET2 network is based on DWDM infrastructure.

CESNET2 network is connected to European GEANT network.

More information about the CESNET2 network can be found on the [[https://www.cesnet.cz|CESNET website]].

===== Data Storage =====
MetaCentrum provides various storage solutions for research data, including home directories, scratch storage for computation, and long-term archival storage.

  * Home directories for personal data
  * Scratch storage for temporary computation data
  * Archival storage for long-term preservation
  * Shared project storage for collaboration
